Менеджер заметок. Написан на Python. Консоль, без сложных GUI.

Заметки удобно хранятся по пути main > notes, без сложных названий, какое название дали вы - такое присвоилось и .txt файлу

Основной плюс в том, что не ест оперативку и процессор.

Все варианты допустимых ошибок предусмотрены. Умеет удалять и редактировать заметки.
