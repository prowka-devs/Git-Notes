Менеджер заметок. Написан на Python. Консоль, без сложных GUI.

Заметки удобно хранятся по пути main > notes, без сложных названий, какое название дали вы - такое присвоилось и .txt файлу

Основной плюс в том, что не ест оперативку и процессор.

Инструкция по установке и работе:

1. Скачайте. Выберите справа в репозитории Releases и установите новую версию
3. Создайте папку с любым названием, расспакуйте туда скачанную .zip
4. Зайдите в созданную папку, двоиным нажатием по "GitNote.exe" откройте исполняемый файл
5. Приступите к работе с GitNote
