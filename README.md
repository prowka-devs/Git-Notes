Заметки хранятся по пути: main > notes в формате .txt.
Для переноса заметок на другую систему просто замените папку notes на другом компьютере, программа адаптируется.

Установка и запуск

1. Перейдите в раздел Releases справа на странице репозитория и скачайте последнюю версию.
2. Создайте папку и распакуйте в неё скачанный .zip архив.
3. Откройте папку и запустите GitNote.exe двойным кликом
